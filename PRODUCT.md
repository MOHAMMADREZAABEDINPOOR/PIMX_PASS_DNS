# PIMX PASS DNS

## Platform
Web. Responsive from 300 CSS pixels upward, with installable and offline capabilities.

## Product truth
A Persian/English personal DNS laboratory. Visitors compare resolvers on their own connection, understand the measurement, keep network-specific history, and configure a compatible resolver on their device. React, TypeScript and Vite are the established stack. Cloudflare Pages and the existing optional D1 analytics API are the deployment context.

## Confirmed scope
The user approved a complete graphite redesign with a signature interactive 3D network, purposeful motion and text effects, live scanning, comparisons, use-case recommendations, history, favorites, custom resolvers, device guides, exports, QR, PWA, monitored service health, responsive behavior and SEO. The user explicitly authorized implementation after earlier proposal rounds. Preserve Persian/English and light/dark settings, source catalogs and the existing administration route. Write natural, specific copy.

## Data and constraints
No invented measurements, uptime, claims or provider verification. Distinguish actual DNS-over-HTTPS queries from HTTPS reachability and protocols a browser cannot test. DNS changes cannot promise improved game-server latency. History and preferences live locally. Shared reports omit network identity. Scheduled global monitoring requires deployment and a KV binding. The browser test and edge monitoring measure different network paths.

## Stack
Existing React/Vite/TypeScript maintained. Three.js for the live network, Framer Motion for transitions, local fonts, compiled CSS, QR encoding. Cloudflare Worker scheduled monitoring and Pages API supplied as deployable source; no external publishing requested.
